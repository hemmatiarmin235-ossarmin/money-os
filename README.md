# 💰 MONEY.OS

> A modern, lightweight personal finance dashboard built entirely with HTML, CSS and JavaScript.

MONEY.OS is a privacy-focused personal finance management web app designed to help you manage your money, accounts, expenses, income, installments and savings goals from a single clean dashboard.

## ✨ Features

- 💰 Manage multiple accounts
- 📊 Financial dashboard and statistics
- 💵 Track income and expenses
- 💳 Categorize transactions
- 📅 Installment management
- 🎯 Savings goals
- 📈 Interactive financial charts
- 🔎 Search and filter transactions
- 🔔 Payment and installment reminders
- 📊 Spending and income analysis
- 💾 Local data storage
- 📤 Export financial data
- 📥 Import saved data
- 🔄 Reset application data
- 📱 Mobile-first responsive design
- 🖥️ Desktop support
- 🌙 Modern dark interface
- ✨ Subtle glassmorphism UI
- ⚡ Lightweight and fast

## 🔒 Privacy

MONEY.OS is designed with privacy in mind.

Your financial data is stored locally on your device using browser storage.

No account is required.

No external database is used.

No personal financial data is sent to a backend server.

## 🛠️ Technology

MONEY.OS is built with:

- HTML5
- CSS3
- JavaScript
- LocalStorage / IndexedDB
- Chart.js
- Responsive Web Design

## 📦 Installation

No installation is required.

Simply open:

`index.html`

in a modern web browser.
